# 👤 Personal Portfolio Website — Node.js & Express

[![Node.js](https://img.shields.io/badge/Node.js-18%2B-green.svg)](https://nodejs.org/)
[![Express](https://img.shields.io/badge/Express-4.x-lightgrey.svg)](https://expressjs.com/)
[![Handlebars](https://img.shields.io/badge/View-Handlebars-orange.svg)](https://handlebarsjs.com/)

A modern personal portfolio web application built with Node.js, Express, and Handlebars templating. Designed to showcase engineering projects, skills, contact forms, and career background.

---

## ✨ Features
- **Dynamic Templating:** Handlebars partials for header, footer, and navigation.
- **Project Showcase:** Highlights technical projects, source code links, and tech stack details.
- **Contact Form:** Interactive contact form route integrated with Express backend validation.
- **Responsive Styling:** Mobile-friendly responsive layout with custom CSS animations.

---

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js
- **Templating Engine:** Handlebars (`hbs`)
- **Frontend:** HTML5, CSS3, JavaScript ES6

---

## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/gaurav2612gupta/PersonalPortfolio.git
cd PersonalPortfolio

# Install dependencies
npm install

# Start server
npm start
```
Open `http://localhost:3000` to view the website.
